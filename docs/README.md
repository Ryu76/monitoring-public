# 통합관제 문서 인덱스

모든 프로젝트 문서는 목적별로 이 `docs/` 아래에서 관리한다.

| 분류 | 내용 |
| --- | --- |
| `01_requirements/` | 요구사항·상세 설계 |
| `02_architecture/` | Agent·Worker·Scheduler 아키텍처 |
| `03_planning/` | PRD, 구현계획, 로드맵, 작업 목록 |
| `04_product/` | 화면·사용 흐름·워크스루 |
| `05_api/` | API 계약 |
| `06_quality/` | 테스트 계획·케이스·결과·결함·운영 전 QA 산출물 |
| `07_status/` | 진행 현황 및 검증 기록 |

운영 DB, 인증 정보, 토큰, 비밀번호, 실제 연결 문자열은 문서에 기록하지 않는다.

# 통합관제 테스트 계획서

## 목표

`프로그램_개발사업_테스트_계획_및_수행가이드.md`의 단위→기능→통합→DB→API→예외→성능→보안→UAT→회귀 순서를 통합관제에 적용한다.

## 환경

- Python: Conda `monitor_backend` (Python 3.12.2)
- Frontend: Node lockfile 기준 `npm ci`
- DB: 운영 Oracle 금지. 전용 개발 Oracle 또는 승인된 일회성 개발 DB만 허용
- 외부 알림: 실제 채널 발송 금지. 안전한 mock/test channel만 허용

## 현재 실행 범위

1. 정적·단위: Conda pytest, Python compile, frontend typecheck/build
2. 계약: 인증/권한, Agent 승인, metric validation, spool ACK, current/history 순서 보장
3. 통합: 전용 개발 DB가 준비된 뒤 Agent→API→DB→UI
4. 브라우저: 로그인 가드, dashboard, server detail, agents/events/incidents의 정상·오류·권한 흐름

## 완료 기준

Critical/High 결함 0건, 선언된 테스트 명령 성공, 운영 DB 없이 통합 증거 확보, 알려진 제한·잔여 위험 기록, UAT 및 배포 전 체크리스트는 담당자 검토 후 완료 처리한다.

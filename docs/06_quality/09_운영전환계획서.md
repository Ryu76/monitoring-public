# 통합관제 운영전환 계획서

## 원칙

운영 Oracle·운영 Agent·실제 알림 채널은 명시적인 최종 승인 전까지 사용하지 않는다.

## 전환 선행 조건

1. 격리 개발 DB에서 Agent→API→DB→UI E2E 및 rollback 검증
2. 데이터 보관/partition/backup/복구 절차 검증
3. 운영 secret injection 및 최소권한 계정 확인
4. 배포·rollback 리허설, 모니터링/로그/알림 수신 확인
5. UAT 승인 및 Critical/High 결함 0건

## 상태

개발 DB·운영 전환 승인 대기.

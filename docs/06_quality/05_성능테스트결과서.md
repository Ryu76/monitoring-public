# 통합관제 성능 테스트 결과서

## 목표

- 일반 조회: 3초 이내
- 등록/수정: 3초 이내
- 대량 조회: 5초 이내
- 최근 24시간 차트: 5초 이내

## 상태

현재 전용 개발 DB·부하 도구·대표 데이터량이 준비되지 않아 실행하지 않았다. 운영 DB를 대상으로 한 성능/부하 테스트는 금지한다.

## 향후 기록 항목

동시 사용자 수, Agent 수, metric batch 크기, 응답 시간 p50/p95/p99, 오류율, CPU/Memory/DB connection, slow query, 실행 명령·환경을 기록한다.
